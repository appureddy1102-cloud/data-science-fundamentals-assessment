# Data Science Fundamentals Assessment

**Student:** Tallapureddy Aparna Reddy  
**Internship submission** · **GitHub:** `appureddy1102-cloud`

A beginner-friendly, reproducible project demonstrating Python, statistics, data types, preprocessing, exploratory data analysis, essential scientific Python libraries, basic machine learning, and responsible data practices. The practical mini-project analyzes a deterministic **synthetic** retail dataset; it is educational data, not actual company or customer performance.

## Objectives

- Explain foundational Python syntax, data structures and exception handling.
- Apply descriptive statistics and interpret association carefully.
- Validate and clean a small tabular dataset using Pandas.
- Generate EDA summaries and clear visualizations.
- Demonstrate a simple supervised regression workflow with a held-out test split.
- Communicate reproducibility, ethical handling and limitations.

## Dataset

`data/sample_dataset.csv` contains 161 rows: 160 generated order lines and one intentional duplicate. Three region values are intentionally missing. It includes order date/ID, customer ID, region, segment, category, units, unit price, discount, revenue and profit. The data are synthetic and generated deterministically from seed 42 by `src/data_analysis.py`. Missing values and duplicate rows are deliberate quality-check examples. No private or business-confidential information is included.

Observed after cleaning: 157 rows remain. All sample outcomes are generated by code; figures should not be represented as real-world business results.

## Technologies and prerequisites

Python 3.10+ recommended. Main dependencies: NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, Jupyter and nbformat/nbclient. Install with:

```bash
python -m venv .venv
# macOS/Linux
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Run the project

From the repository root:

```bash
python src/data_analysis.py
jupyter notebook data_science_fundamentals.ipynb
```

The analysis script validates/cleans the CSV, prints the audit/KPIs/category summary and regenerates PNG charts plus CSV tables under `outputs/`. The notebook is saved with executed outputs. The report code examples are educational and are consistent with the project implementation.

## Main learning outcomes

- Separate raw and cleaned data; count duplicates/missing core fields.
- Distinguish discrete/continuous and nominal/ordinal data.
- Calculate mean, median, mode, variance, standard deviation, quartiles and IQR.
- Use groupby summaries, histograms, boxplots, trends, scatterplots and correlation heatmaps.
- Explain train/test separation, overfitting and association-versus-causation.
- Use a seed to reproduce synthetic examples, version files with Git, and disclose assumptions.

## Limitations and responsible use

The dataset is intentionally synthetic and small. Its relationships are designed for demonstration, and its findings do not generalize to a real business. The negative discount/profit relationship is influenced by the synthetic generation rule. No causal claims or real business recommendations should be inferred. For actual data, obtain permission, minimize sensitive fields, document provenance, validate representativeness and handle privacy/security appropriately.
