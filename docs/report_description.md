This internship submission demonstrates foundational data science skills through a structured report, an executed Jupyter Notebook, and a reproducible Python mini-project. The written assessment introduces the data science lifecycle and explains Python variables, data types, operators, control flow, loops, functions, collections, and exception handling. It also covers descriptive statistics, probability, correlation, hypothesis testing, data measurement scales, structured and unstructured data, data acquisition, preprocessing, exploratory analysis, scientific Python libraries, introductory machine learning, and responsible industry practices.

The practical exercise uses a deterministic synthetic retail dataset generated specifically for educational purposes. It contains 160 generated order records plus an intentional duplicate and three missing region values, allowing the cleaning process to be demonstrated transparently. The reusable analysis code inspects the raw file, checks data types and data quality, removes exact duplicates, parses dates and numbers, filters incomplete core records, calculates descriptive statistics and business summaries, and saves five visualizations and two tabular outputs. The Jupyter Notebook includes foundational Python and statistics examples, EDA charts, a basic Scikit-learn regression demonstration with a reproducible train/test split, and interpretation of the observed results. The Word report adds a professionally formatted cover page, table of contents, practical code examples and outputs, statistical formulas, a mini-project walkthrough, sixteen assessment questions with answers, learning outcomes, and links to official documentation.

All generated figures and reported mini-project values are derived from the included synthetic sample and the fixed random seed. They are not real company results and should not be used as market evidence. The project emphasizes reproducibility, clear documentation, privacy and security awareness, honest communication of limitations, and the distinction between correlation and causation. Setup instructions and dependencies are supplied so another learner can rerun the notebook and analysis script locally.
